# m1-registre-alias

**Public :** l'apprenant.

Enregistrer des modèles dans le registre MLflow, pointer des alias sur des
versions et charger un modèle par alias.

## Prérequis

Docker, `uv`, `git`, avoir joué `m1-mlflow-serveur`. Démarrer le socle avant
`dsoxlab run` : `bash scripts/socle-demarrer.sh mlflow`. Arrêt :
`bash scripts/socle-arreter.sh`.
