# m1-registre-alias

**Audience:** the learner.

Register models in the MLflow registry, point aliases at versions and load a
model by alias.

## Prerequisites

Docker, `uv`, `git`, having played `m1-mlflow-serveur`. Start the stack before
`dsoxlab run`: `bash scripts/socle-demarrer.sh mlflow`. Stop it with
`bash scripts/socle-arreter.sh`.
