# m1-mlflow-serveur

**Audience:** the learner.

Log a training on an MLflow server (PostgreSQL + S3) and find which run
produced a given model.

## Prerequisites

Docker, `uv`, `git`, having played `m1-dvc-pipeline`. Start the stack before
`dsoxlab run`: `bash scripts/socle-demarrer.sh mlflow`. Stop it with
`bash scripts/socle-arreter.sh`.
