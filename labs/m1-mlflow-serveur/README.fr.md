# m1-mlflow-serveur

**Public :** l'apprenant.

Journaliser un entraînement sur un serveur MLflow (PostgreSQL + S3) et
retrouver le run qui a produit un modèle donné.

## Prérequis

Docker, `uv`, `git`, avoir joué `m1-dvc-pipeline`. Démarrer le socle avant
`dsoxlab run` : `bash scripts/socle-demarrer.sh mlflow`. Arrêt :
`bash scripts/socle-arreter.sh`.
