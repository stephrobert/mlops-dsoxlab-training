# m1-dvc-pipeline

**Public :** l'apprenant.

Décrire un entraînement en pipeline DVC (`dvc.yaml`, `params.yaml`) et le
rejouer à l'identique.

## Prérequis

Docker, `uv`, `git`, avoir joué `m1-dvc-donnees`. Démarrer le socle avant
`dsoxlab run` : `bash scripts/socle-demarrer.sh`. Clés S3 :
`set -a; source shared/socle/.env; set +a`. Arrêt : `bash scripts/socle-arreter.sh`.
