# m1-dvc-pipeline

**Audience:** the learner.

Describe a training as a DVC pipeline (`dvc.yaml`, `params.yaml`) and replay it
identically.

## Prerequisites

Docker, `uv`, `git`, having played `m1-dvc-donnees`. Start the stack before
`dsoxlab run`: `bash scripts/socle-demarrer.sh`. S3 keys:
`set -a; source shared/socle/.env; set +a`. Stop: `bash scripts/socle-arreter.sh`.
